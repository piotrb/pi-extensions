- **Live `tool_call` gate shows a streaming widget above the editor.** The gate previously only updated the single-line status bar with coarse-grained phases (`querying…` / `thinking…` / `responding…`). When the user runs a `bash` command that takes a few seconds to evaluate, they get a live, line-by-line view of what the model is reasoning and emitting — same shape as `/do-it-right` → Test Evaluation has always shown. The widget appears when the model starts streaming, persists with the verdict marker + reason for ~1.5s (allow) or ~4s (block), then clears.
- **Streaming widget is shared between the live gate and Test Evaluation.** Previously each path had its own ~40 lines of inline buffer/render code with duplicated truncation + line-split logic. Both paths now go through `startStreamingWidget(command, ctx)` in `packages/pi-do-it-right/src/lib/streaming-widget.ts`. The Test Evaluation path leaves the widget up indefinitely (it's the user's observation surface); the live gate auto-clears it on timeout.
- **Future-toggle-ready.** `useStreamingWidget(): boolean` is the single branch point. Today it returns `true`. When you want a settings toggle, read it from `~/.pi/agent/auto-reject-rules.json` and flip the body — both paths honor the change in one place.
- **`evaluateStream` streaming contract is now testable.** The test seam (`deps.streamSimple`) was previously only tested via `module-level mocking` in `do-it-right.test.ts`. A new `evaluateStream` test case in `packages/pi-do-it-right/src/lib/evaluate.test.ts` injects a hand-crafted async-iterable stream and asserts that `thinking_delta` / `text_delta` / `thinking_start` / `thinking_end` events reach the callback with their `delta` / `content` payloads intact. This locks the contract the streaming widget depends on; no widget assertions (per project preference to avoid heavily-mocked tests).
- **Toolchain fix.** `format` / `format:check` in root `package.json` no longer break the `prettier` arg-passing chain. Invocation now matches POSIX convention — `pnpm format` defaults to `.`, `pnpm format packages/foo` formats a single path.
